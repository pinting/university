# University notes

> ### A PDF-eket az `out` mappában találjátok A4 / A5 / A6 lapméretekben!
> ### The PDFs are in the `out` folder in A4 / A5 / A6 paper sizes!

## Build

Install the required dependencies then build the project.

```bash
sudo pacman -S --needed \
  make \
  pandoc-cli \
  texlive-basic \
  texlive-latex \
  texlive-latexrecommended \
  texlive-latexextra \
  texlive-xetex \
  texlive-pictures \
  texlive-fontsrecommended \
  texlive-fontsextra \
  texlive-mathscience \
  gnu-free-fonts

make
```
