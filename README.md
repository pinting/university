# ELTE Matematika BSc 2026 university materials

## Build

Install the required dependencies then build the project.

```bash
sudo pacman -S --needed \
  make \
  pandoc-cli \
  texlive-basic \
  texlive-latex \
  texlive-latexrecommended \
  texlive-latexextra \
  texlive-xetex \
  texlive-pictures \
  texlive-fontsrecommended \
  texlive-fontsextra \
  texlive-mathscience \
  gnu-free-fonts

make
```
